# Michael Futol — Chinaimo Project Controls Assessment

Auditable project-controls technical assessment demonstrating the exact requested deliverables for a Chinaimo Water Treatment Plant–style mock project.

## Submission structure

1. **BOQ, Measurement & Progress** — BOQ, monthly quantities, weighted progress, Planned vs Actual, Gantt and S-Curve.
2. **Planning & Scheduling** — WBS, activity durations, logic/dependencies, baseline, critical path, delay update and forecast completion.
3. **Monthly Progress / Payment Claim** — Previous, Current, Cumulative and Remaining quantities/amounts with BOQ consistency checks.

## Data boundary

Publicly available Chinaimo / Vientiane Capital Water Supply Expansion scope was used only to shape the mock WBS. The assessment quantities, unit rates, durations, logic, progress, claims and delay scenarios are illustrative and are **not** Kubota Construction contract data.

## Control model

- **Excel** — BOQ, measurement, progress, claim and reporting source of truth.
- **Microsoft Project** — CPM schedule engine for logic, baseline, critical path, float and forecast.
- **Web presentation** — reviewer-facing evidence room using the same WBS / Activity / BOQ IDs.

## Native deliverables

The site provides direct downloads for the working Excel workbook and Microsoft Project schedule outputs after final QA.
