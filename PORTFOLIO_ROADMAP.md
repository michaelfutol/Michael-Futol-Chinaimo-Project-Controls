# MUNIGEN Portfolio Evolution

This branch is a safe duplicate of the Chinaimo Project Controls assessment site. The production Chinaimo submission on `main` remains frozen and reviewer-safe.

## Portfolio direction

The portfolio will evolve from the Chinaimo visual and interaction language into a broader professional project-control / engineering portfolio.

### Information architecture

1. Home / Profile
2. Selected Work
3. Case Studies
4. Engineer's Notes
5. Labs / Experiments
6. Services
7. Credentials
8. Contact

- Water / GIS / Digital Twin work
- SouqADL procurement-intelligence experiments

### Design doctrine

Preserve the restrained Japanese-minimal / late-20th-century technical-paper character developed for Chinaimo: warm off-white paper, technical drafting cues, restrained serif display typography, clear hierarchy, strong project evidence, minimal decoration, and readable full-browser technical documents. Avoid generic AI-tech visuals.

### Core principle

The portfolio should show evidence and working systems rather than rely on marketing claims. Each project should be able to expose project context, role, methods, deliverables, technical decisions, QA, lessons, and live/interactive artifacts where appropriate.
